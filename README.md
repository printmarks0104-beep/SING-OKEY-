# SING'OKEY

A glassmorphism karaoke & entertainment web app inspired by LetSingOke v4.4.2.

## Features
- **Stage**: Synchronized syllable-by-syllable karaoke lyrics, Web Audio polyphonic MIDI synthesizer, live Pitch Guide & microphone pitch detection, key shift (`-6` to `+6`), tempo control (`0.75x`–`1.25x`), lyric sync offset, audience reactions, and animated score card export.
- **Songbook**: Search by title, artist, or song code; reserve to queue; import custom `.mid`/`.kar` or `.mp3` + `.lrc` files; export songbook CSV.
- **Oke Arcade**: Playable *Beat Drop Oke*, *Pulse Oke*, *Pitch Perfect*, *Guess a Song*, and *Score Records*.
- **Movie Oke & TV Oke**: Glassmorphism video player supporting MP4/WebM/HLS (`.m3u8`) streams and live IPTV country playlists.
- **Web Remote & Mic FX**: 0–9 song code keypad, playback deck, and live microphone Gain, Echo, and Reverb controls.

## Hosting
Enable **Settings → Pages → Deploy from branch (`main` / `/ (root)`)** to run **SING'OKEY** on GitHub Pages.
