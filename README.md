# SINGOKEY

An immersive glassmorphism karaoke & entertainment web app featuring a curved floating glass dock, stage song marquee, 5-band Studio Equalizer, Pitch Guide, Oke Arcade, Movie Oke, TV Oke, and Web Remote.

## Features
- **Immersive Glass Stage**: Synchronized syllable-by-syllable karaoke lyrics, Web Audio polyphonic MIDI synthesizer, live Pitch Guide & microphone pitch detection, song marquee ticker, key shift (`-6` to `+6`), tempo control (`0.75x`–`1.25x`), lyric sync offset, audience reactions, and animated score card export.
- **Studio Equalizer & Mic FX**: 5-band Web Audio equalizer (`60Hz`–`14kHz`) with presets (*Flat*, *Karaoke Vocal*, *Bass Boost*, *Concert Hall*) plus live microphone Gain, Echo, and Reverb.
- **Songbook**: Search by title, artist, or song code; reserve to queue; import custom `.mid`/`.kar` or `.mp3` + `.lrc` files; export songbook CSV.
- **Oke Arcade**: Playable *Beat Drop Oke*, *Pulse Oke*, *Pitch Perfect*, *Guess a Song*, and *Score Records*.
- **Movie Oke & TV Oke**: Glassmorphism video player supporting MP4/WebM/HLS (`.m3u8`) streams and live IPTV country playlists.
- **Web Remote**: 0–9 song code keypad, playback deck, and live stage reactions.

## Hosting
Enable **Settings → Pages → Deploy from branch (`main` / `/ (root)`)** to run **SINGOKEY** on GitHub Pages.
